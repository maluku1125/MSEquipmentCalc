# TMS 楓之谷裝備模擬計算機

---

## 開始之前:先切成打王 Set

工具讀的是 **API 上的角色面板**,而 API 只會記錄你最後一次登出時的狀態。

所以請先:**把裝備切換成打王配置 → 上下線一次 → 再來查詢**。
不然算出來的會是你平常掛機或練功的配置,數字會對不上。

> API 資料約每 20 分鐘更新一次,下線後如果查到的還是舊資料,等幾分鐘再試。

---

## ① 角色查詢

輸入角色名稱按查詢即可,不需要申請任何金鑰。

查詢過的角色會記在下方,之後點名字就能直接叫出來,不用重打。
點 × 可以移除單筆紀錄。

> 如果你想用自己的 NEXON API Key,可以展開最上方那行灰色的「API 設定」自行填入。
> 一般使用者不需要理會這個區塊。

---

## ② 角色機體

查詢成功後會顯示兩個分頁:

- **機體資訊** — 戰鬥力、屬性攻擊力、傷害、BOSS 傷、爆傷、無視防禦、主副屬等完整面板。
  次要數值(掉寶率、楓幣、經驗值等)收在「更多數值」裡。
- **裝備一覽** — 每件裝備的星力、卷軸強化、潛能、附加潛能、靈魂寶珠與屬性總和。
  有裝備欄位切換(Preset 1~3)的話會分頁顯示;圖騰與寶玉只存在於「目前裝備」。

這一步只是確認抓到的資料正確,不需要操作。

---

## ③ 手動填入

有五個數值 **API 沒有提供**,必須自己看遊戲內面板加總後填入。
沒填的欄位會亮橘框並在下方說明「不填會怎樣」,填完就會消失。

| 欄位 | 填什麼 |
|---|---|
| **攻擊%** | 裝備潛能、被動、聯盟、連結等提供的攻擊力%(不是面板攻擊力) |
| **主屬%** | 同上,主屬性的百分比加成總和 |
| **不吃%主屬** | 不受百分比影響的主屬,主要是**符文(阿爾卡那 / 真實)** |
| **副屬%** | 副屬性的百分比加成總和 |
| **不吃%副屬** | 不受百分比影響的副屬 |

填完後下方會顯示**反推出來的裸值**


這是拿來檢查你填的數字對不對用的。如果裸值算出來明顯不合理(例如主屬只剩幾百),
代表百分比或符文的數字填錯了,可以回頭對一下。

### 爆發設定

| 欄位 | 說明 |
|---|---|
| **估計爆發占比%** | 你的傷害有多少比例是在爆發期打出來的,預設 50 |
| **爆發窗秒數** | 一輪爆發大約持續幾秒,預設 20 |

這兩個值會決定爆發技能(規範戒指、靈魂契約、一擊必殺)要算多少效益,詳見下一步。

---

## ④ Buff 加成

**這一步很重要,不填的話算出來的數字會偏高。**

原因:API 給的面板是**沒吃 buff 的狀態**。但你實戰時 BOSS 傷可能從 625% 變成 700%+,
分母不一樣,同一件裝備算出來的提升幅度就不一樣。勾選 buff 之後,增幅才是以實戰狀態計算的。

分成三個分頁,把你**實際會吃到**的勾起來:

- **技能** — 公會技能、冠軍庇護、各式戒指、五轉被動、AUT 加成等
- **藥水** — 星星藥水、靈藥、椅子、VIP、地圖天氣等
- **連結技能** — 他人 12 條 + 自身 1 條(自身那條會標藍色「自身」標籤,不佔額度)

有等級的項目可以下拉選等級。**已勾選但沒滿等的項目,右邊會顯示綠色的「滿等 +X.XX%」**,
告訴你把它升滿能多幾 % 傷害 —— 拿來排優先順序很好用。

### 冷機 / 熱機

- **熱機** — 套用所有勾選的 buff(正常使用)
- **冷機** — 暫時當作完全沒吃 buff,但**勾選內容會保留**,隨時可以切回來

拿來快速比較「有 buff / 沒 buff」兩種狀態的差別。

### 幾個特別的處理

- **互斥項目**:紅星星/藍星星、275椅子/榮譽靈藥、夕陽/午夜、一擊必殺對軸/不對軸,
  各組只能選一個,勾了新的會自動取消舊的。
- **爆發專用技能**(規範戒指、靈魂契約、一擊必殺對軸):
  這些只在爆發窗內生效,工具會依照你填的爆發占比與秒數換算,下方會列出計算過程,例如:

  ```
  爆發窗 20 秒   覆蓋率 = min(持續, 20) ÷ 20
  ・規範戒指 持續 20s → 爆發窗覆蓋 100%:攻擊% 85
  ・靈魂契約 持續 15s → 爆發窗覆蓋 75%:傷害% 45
  ```

  靈魂契約的持續時間會**自動依你的「Buff 持續時間」加成計算**,不用自己算。

## ⑤ 模擬設定

### 基準值

自動帶入 API 面板 + 你勾的 buff,通常不用動。

只有「目標BOSS防禦%」需要視情況調整(預設 300),打不同王防禦率不同,
這個值會影響「無視防禦」的效益評估。

### 模擬變化量

填**差值**,不是填新的數值。想模擬換一件手套多了 30 主屬、10 攻擊力,就填 30 和 10。

| 欄位 | 說明 |
|---|---|
| 主屬 ±(吃%) | 裝備上的主屬,會再乘上你的主屬% |
| 不吃%主屬 ± | 符文那類不受%影響的主屬 |
| 攻擊力 ±(裸攻,會吃%) | 裝備上的攻擊力,會再乘上攻擊% |
| 傷害 / BOSS傷 / 爆傷 ±% | 直接填百分比差值 |
| 無視防禦 ±% | 乘算疊加,填新增或移除的那條數值 |

### 終傷調整(單獨處理)

終傷不能直接加減,因為各來源之間是**互相相乘**的。

所以這裡要填**你要調整的那一項來源**的原先與調整後數值(通常是萌獸終傷)。
例如萌獸終傷從 40% 升到 60%:

```
來源原先 40 → 調整後 60
→ 增幅 ×1.1429(+14.29%),面板終傷 146.36% → 181.55%
```

新增一個來源就把「原先」填 0;拿掉一個來源就把「調整後」填 0。

### 計算結果

按「計算增幅」後會顯示:

```
平時 +3.54% ／ 爆發期 +3.29%(爆發占比 50%,爆發期傷害為平時的 1.43 倍;下方為加權結果)

總體變強:+3.49%
[屬性 +0.00%] [攻擊力 +0.00%] [傷害+BOSS +3.54%] ...
```

下方的方塊是**各乘區的貢獻拆解**,可以看出這次提升主要來自哪個部分。

## ⑥ 儲存方案

算完之後給它一個名字(例如「武器上22星」「換艾特倫手套」),
可以順便填**成本**(單位自訂 —— 雪花、楓幣、台幣都行,同一隻角色用同一種單位就好),
按「儲存目前結果」。

清單支援兩種排序:

- **依增幅** — 純看哪個提升最多
- **依CP值** — 看**每 1% 傷害要花多少成本**,數字越低越划算

每筆方案都能「載入」把數值填回去微調,或直接「刪除」。

> **方案的增幅會即時重算。** 你之後改了 buff、改了手動填入的數值、或重新查詢角色更新面板,
> 所有已儲存的方案都會用**新的基準**重新計算,確保它們永遠站在同一個基礎上比較。
> 如果數字和存檔時不同,增幅欄會標 `*` 並顯示當時的數值。

## 常見問題

**Q:算出來的數字準嗎?**
A:計算引擎有 47 項單元測試,公式與社群通用的計算方式一致。但工具算的是**面板傷害的相對提升**,
不包含技能係數、命中率、走位、Buff 銜接等實戰因素,所以請當作「投資方向的參考」而不是精確預測。

**Q:為什麼我的增幅看起來比別人低?**
A:通常是因為你的基準值比較高。同樣加 30% BOSS 傷,BOSS 傷 300% 的角色能得到 +5.76%,
625% 的角色只有 +3.55% —— 這是正常的邊際遞減,不是算錯。

**Q:惡魔復仇者 / 傑諾 / 雙副屬職業能用嗎?**
A:可以,工具會依職業自動判定。惡魔復仇者以 HP 換算屬性、傑諾三主屬合計、
暗影神偷等雙副屬職業的 STR+DEX 會合併計算。判定錯的話可以在⑤手動改「職業體系」。

**Q:資料會上傳嗎?**
A:不會。所有填寫的數值、勾選的 buff、儲存的方案都只存在你自己的瀏覽器裡(localStorage)。
換一台電腦或清除瀏覽器資料就會消失。

**Q:換角色查詢會蓋掉我的設定嗎?**
A:不會,手動填入、buff 勾選、儲存方案都是**依角色名分開記憶**的。
